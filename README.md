# ENR08-V05 — Maintenance lit médicalisé

Version GitHub Pages mobile/iPhone avec :
- scanner QR Code / Data Matrix / Code 128 / EAN-13 ;
- fenêtre « Scan réussi ! » avec illustration EuroMed ;
- certificat PDF avec conforme en vert et non conforme en rouge ;
- exception : « Propreté générale / aspect extérieur… » en non conforme ne rend pas le matériel globalement non conforme ;
- obsolescence visible dans les commentaires/observations du certificat ;
- suppression de la mention d’essai récurrent NF EN 62353 ;
- **mode maintenance de plusieurs lits avec une seule signature client à la fin**.

## Mode multi-lits

1. Cliquer sur **« Démarrer une tournée multi-lits »**.
2. Remplir et contrôler le premier lit.
3. Cliquer sur **« Enregistrer ce lit et passer au suivant »**.
4. Répéter pour chaque lit.
5. Cliquer sur **« Terminer la tournée et signer »**. Si le dernier lit est encore rempli mais pas enregistré, il est enregistré automatiquement.
6. Le client signe **une seule fois**.
7. **Générer le dossier PDF** crée un seul PDF contenant tous les certificats de la tournée, avec la même signature client sur chaque certificat.
8. Le bouton d’envoi par e-mail transmet également ce dossier PDF unique.

Le mode normal reste disponible pour générer un certificat lit par lit.
