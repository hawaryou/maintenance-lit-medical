# ENR08-V05 – Maintenance lit médical

Projet prêt à importer dans GitHub Pages.

## Installation
1. Importer tous les fichiers à la racine du dépôt GitHub.
2. Activer GitHub Pages sur la branche contenant ces fichiers.
3. Recharger la page avec Ctrl+F5.

L'URL Google Apps Script est intégrée directement dans `app.js`.
